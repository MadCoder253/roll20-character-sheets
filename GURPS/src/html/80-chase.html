Use this sheet to help run chase scenes from GURPS Action 2 Exploits, please refer to pages 31-34. The next iteration will include tooltips and revisions based on input.
Wipeouts: If relevant roll fails by Stability Rating or less, but if on foot, on a regular failure, the result is a Close Call. If roll is over Stability Rating, then result is a Wreck. See GURPS Action 2 page 35.
Collateral Damage: On crowded streets, any wipeout causes an accident. If the quarry causes an accident, pursuer has -(1d6-1) to their next chase roll. See GURPS Action 2 page 35.
Lucky Break: The use of luck advantages or character points to manipulate the chase to help you perform a maneuver that normally can't. See GURPS Action 2 page 41.

A brief description of the mode of travel; land, water, air. You could enter land/water for a hovercraft.

Stability Rating of vehicle, if applicable. Used when checking for Wipeouts.

Handling of vehicle, if applicable. This value is applied to the Chase's Final Modifier.

Speed

Speed in yards per second, which is used to get a Chase Speed Modifier and applied to the Chase's Final Modifier.
Speed Modifier:

Static

Check if you selected a static maneuver or you forced into a static state.
If static...
  • No speed bonus
  • If opponent is non-static they get an extra range shift, no matter who wins the contest.
  • If both if you are static, the range band doesn't change.
  • To remove the static you must change your mobility (if possible) or perform a stunt.

Notes

You could use the notes field to show what skill you're using for Chase Quick Contest and additional remember notes.

Chase Skill

Enter the level of the skill chosen for the chase. You can either have the player roll their own skill applying the Final Modifier or use the provided skill button.

Support Actions

Support actions can be used to list passengers, characters in other vehicles, and then detailing actions and how it can impact the chase rolls.
