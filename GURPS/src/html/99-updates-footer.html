Attributes Column

The first display column relates to all the characters attributes, with a couple of options of how to modifier the attribute. Most of the attributes have a Mod field to change the attribute without spending points. This is useful if you have advantages that modifier an attribute, or perhaps there are enhancements or limitations that were applied to the attribute that would change the character point cost.

There's a field to enter character points, the Character Sheet will use the Rules as Written for cost of attributes. If you enter 20 points for Health, the final Health attribute will be 12.

Notes

Strength and Size Modifier: On the Bio\Misc tab, you can enter your character's size modifier, there's also a checkbox to apply the Size Cost Modifier. Checking this will change the points per level cost. The character sheet will show a message if you didn't spend the exact amount of character points to get a specific ST. For example: If you have a Size Modifier of 2 and enter 50 points for the Strength attribute you will see this error message.

  • Warning! Due to your Size Modifier 2 you only need to spend 48 character points (8 pts/level) for Strength 16.

Speed Attribute: There's a clock icon that you can use to add your character to the turn order. Click your character's token and then on the character sheet, go to the General tab and click the clock icon.

  • When your character is added to the turn order the speed will be your Basic Speed + Dexterity attribute. DX was added to help break ties. B363.

Thrust and Swing Damage: Near the bottom is a field called Striking for Striking Strength. This field is used to calculate Thrust and Swing Damage. Changing the effective Striking Strength will update Thrust and Swing damage. You can change Striking Strength by changing your Strength Attribute or changing Striking Strength by using the modifier or character point column. If you notice after using the import feature the Thrust and Swing damage appear wrong, like 1d6-6, try changing the Strength attribute to force the damage die to update.

The middle portion of the Character Sheet has two columns, one for additional stats and a notes section.

There's an area for entering your own custom Pools, you could use them to track items that have limited users per day, an additional energy reserve, etc.

Encumbrance Section

The middle-middle portion of the Character Sheet has an encumbrance block. By default, it is collapsed, and it will show your current encumbrance level and related movements. Here's the formatting of movement values.

  • 0 or 0 (0): Movement type isn't available.
  • 5 (1): Means you can move 5 yards in one second and have a step of 1.
  • 6/12 (1): Means you have an acceleration of 6 yards per second, with a top speed of 12 yards per second, with a step of 1.

Expandable button. Click the button to see full encumbrance chart.

This section can be used to calculate high speed movement modifiers, such as turning radius, deceleration penalty, and tight turn penalty.

Character Point Summary

The right-column is reserved for the Character Point Summary. It's important to note that the Character Sheet doesn't track rules for character creation, such as having only "-75 points in disadvantages" and "-5 points in quirks", etc. That should be part of the process of the building a character.

  • Total Field: Use this field to keep track of your character's total points, it's important to keep this field up to date if you're letting the character sheet to keep track of unspent points.
  • Spent and Unspent Fields: These fields are automatically calculated. Unspent = Total Field - Spent Field.
  • Point Summary: You can select what type of point summary to see on the options tab. You can select GCA4, GCA5, GCS, and Detailed. You can hover over the labels to see how the point summaries are calculated.

Languages

There's a checkbox for Language Talent, if checked the repeating table for languages will use a different cost for Spoken and Written.

There's also a repeating table for adding as many languages as needed, along with selecting the Spoken and Written level and fields to modify the cost depending on special campaign rules.

Special Note: This applies only to character building. Roll20 simply totals all the points and doesn't consider rule limitations. If illiteracy is the norm, the GM should not count these points against the disadvantage limit. Basically, if you're illiterate you get free points that don't count against the disadvantage limit when building a character.

At the bottom of the table is the summary, with the ability to change the effective gravity of the world you're on. The Grand Total Weight includes your carried items plus your weight that was entered on the Bio/Misc tab.

Tips

Roll20 doesn't support nested tables, so it's not possible to add a sub-table beneath an item, like having a backpack and adding items to the backpack. To get around that, you can order the items and then indent child items using spaces.

Grimoire Tab

The tab starts with an expandable notes section and is followed by a spell attributes toolbar that is used by the Spell Table.

Spell Toolbar

You need to select which attribute the spells will be based on, followed by a field to enter the modifier, such as Magery, Power Investiture, and other modifiers. Unfortunately, this is a legacy table and it is limiting if you want to have spells based on other stats or if you have a special case where a character has two different types of Magery or maybe even in the rare case of having Magery and Power Investiture. In those cases, the best approach is to use the individual spells modifier field to get the desired skill level.

There are two more read-only fields that provide feedback on spell penalties. The ON PENALTY field shows the total skill roll penalty for having one or more spells "on", the CONCENTRATION PENALTY field shows the total skill roll penalty if you are concentrating on one or more spells. Important the penalties will be automatically added to your effective spell skill level.

Spells Table

The spell table consists of a checkbox to highlight the row, fields for spell name, a clickable die icon for spell's skill roll, the final effective skill level, the Difficulty level, a modifier field (handy for permanent/long term modifiers, such as talent modifiers, equipment modifiers, etc.), the character points spent on the spell, a number field for ON which allows you to enter a value for the number of spells that currently in effect, a number field for the number of spells you're currently concentrating on, duration of spell, initial energy cost, time to cast, and maintenance cost.

Expanded Notes Section

You can expand the spell to see additional fields. The first field to notice is the Row ID field, which is read-only. You can use this ID to link the spell to Techniques, Active Defenses, Melee Attacks, or Ranged Attacks. There are also fields to enter additional information about the spell (to avoid having to find the spell in a book) and for success/fail notes.

Tips

Take the time to fill out as much information as you can about the spell, especially the notes for success and fail, this will Help save time, instead of trying to find the information.

GCS Instructions

There is an initial GCS export file available that you can add to your GCS User Library. Once you have it in your library, you can export your character to a Json file.

  • Open GCS
  • Under the Library Explorer, right-click on User Library and then click on Show on Disk.
  • Create a new folder named Output Templates
  • In that folder create an empty file named Roll20.json
  • Use the link below so you can get the file contents. NOTE: The best method is to download the file and open it in a editor like Notepad.
  • Copy the file contents into the file you named Roll20.json
  • To Export to Roll20, in GCS go to File > Export to... > User Library > Roll20.
  • Important: After importing you will need to verify the content and adjust accordingly. Due to the limitations of the Go text/template system, which is standard for templating systems, it allows a limited set of coding logic.

NOTE: This file is a work in progress and may not be up to date with the latest changes to GCS, and it hasn't been thoroughly tested, I've imported four characters so far. Please report any issues or suggestions on the Roll20 Forum.
